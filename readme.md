# UG College Admission Predictor & Chatbot

A comprehensive web application for +2 students to predict college admissions and get counselling guidance.

## Features

- **College Prediction**: Enter your marks and category to get matched with suitable colleges
- **Smart Categorization**: Colleges are categorized as Safe, Borderline, or Dream
- **Interactive Chatbot**: Get instant answers about cutoffs, college selection, and preference strategy
- **Community Relaxations**: Automatic application of community-based cutoff relaxations
- **Responsive Design**: Works on desktop and mobile devices
